This is a future feature and is not part of the initial release. We plan to ask for users’ consent before using their saved lists for recommendations.

About cineka

cineka (working title) is a non-commercial web application currently under development. It will let users select and save up to nine favorite films and create a shareable poster collage, with recommendations based on other users’ lists planned for a later release.

We plan to use the TMDB API to search for movies and retrieve titles, release dates, and poster images. This page introduces the project; the application is not yet publicly available.

Movie information and posters will be provided by the TMDB API. No movie data or posters are used on this introduction page.

This product uses the TMDB API but is not endorsed or certified by TMDB.
