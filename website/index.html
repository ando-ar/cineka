好きな映画から、
次の一本へ。

あなたの好きな映画を、最大9本。
選んで、並べて、一枚の画像に。
cinekaは、映画の好みを共有するWebアプリです。

現在開発中です。アプリはまだ一般公開していません。
サービス名・機能・公開時期は変更になる場合があります。

最初の公開でできること

好きな映画を選ぶ

映画を検索し、好きな作品を1〜9本選んで、自分のリストを作れます。

画像にして共有する

選んだ映画のポスターと作品名を一枚にまとめ、画像をダウンロードしてSNSで共有できます。

リストを保存する

ログインしてリストを保存し、あとから開いたり、作品を選び直したりできます。

将来の構想です。初期公開には含みません。保存済みリストの推薦への利用は、参加への同意を確認したうえで行う予定です。

About cineka

cineka (working title) is a non-commercial web application currently under development. Users will be able to search for movies, select up to nine favorite films, save their selection, and generate a poster collage for download and sharing on social media.

A future feature will recommend movies using film lists saved by other users, with participation based on user consent. This recommendation feature is not part of the initial release.

We plan to use the TMDB API to search for movies and retrieve titles, release dates, and poster images. This page introduces the project; the application is not yet publicly available.

映画情報・ポスターの取得にはTMDB APIを利用する予定です。この紹介ページでは映画データ・ポスターを使用していません。

This product uses the TMDB API but is not endorsed or certified by TMDB.
